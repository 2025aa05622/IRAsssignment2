# Intelligent Information Retrieval System


## Features

- Web Crawling
- Duplicate Detection
- Text Mining
- Inverted Index
- TF-IDF Search
- PageRank Ranking
- Content Recommendation
- IR Evaluation
- Analytics Dashboard


## Installation


pip install -r requirements.txt



## Run


streamlit run app.py



## Algorithms

### Search

TF-IDF + Cosine Similarity


### Ranking

PageRank


### Recommendation

Content Based Filtering


### Evaluation

Precision

Recall

F1

MAP

MRR

NDCG


## Conclusion

This project demonstrates a complete end-to-end Information Retrieval pipeline.
